01 / Setup

Installation

DeepGPR is published on PyPI. Install the package into the environment that already contains the PyTorch build appropriate for your hardware.

terminal
pip install DeepGPR
DeepGPR uses packaged native libraries. CUDA execution additionally requires an NVIDIA GPU, a CUDA-enabled PyTorch installation, and a compatible CUDA backend library.
02 / Environment

Requirements

Python

Python 3.8+

The package metadata requires Python 3.8 or newer.

Libraries

Scientific Python stack

PyTorch, NumPy, SciPy, and Matplotlib are declared runtime dependencies.

CPU

Linux, Windows, macOS

The C/OpenMP CPU backend supports all three operating-system families listed by the project.

CUDA

Linux and Windows

CUDA execution is documented for Linux and Windows and requires an NVIDIA GPU with sufficient VRAM.

03 / Basic usage

Run a differentiable forward model

The model tensors use relative permittivity eps_r and electrical conductivity sigma. A 2D model is represented with a singleton third spatial dimension.

quick_start.py
import torch
import DeepGPR

device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
dx, dt, nt = 0.02, 3e-11, 500

eps_r = torch.full((64, 96, 1), 4.0, device=device, requires_grad=True)
sigma = torch.zeros_like(eps_r)
source_location = torch.tensor([[[16, 12, 0]]], device=device)
receiver_location = torch.tensor([[[48, 12, 0]]], device=device)

source = DeepGPR.wavelet.ricker(
    2e8, nt, dt, 5e-9, device=device
).reshape(1, nt, 1)

result = DeepGPR.compute(
    device=device,
    dx=dx,
    dt=dt,
    source_amplitudes=source,
    source_location=source_location,
    receiver_location=receiver_location,
    eps_r=eps_r,
    sigma=sigma,
)

receiver_data = result[-1]
receiver_data.square().sum().backward()
print(receiver_data.shape, eps_r.grad.shape)

The final tuple element is receiver data with shape (nstep, nt, nrx). Calling backward() populates requested gradients through PyTorch autograd.

04 / Hardware

Device and GPU configuration

Pass either a torch.device or a device string. DeepGPR selects the native backend for that device type.

device_selection.py
# Automatic selection
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")

# Explicit choices
cpu_device = torch.device("cpu")
gpu_device = torch.device("cuda:0")

# Optional CUDA memory control for saved model-gradient wavefields
result = DeepGPR.compute(
    device=gpu_device,
    # model, source, and acquisition arguments...
    wavefield_storage_dtype=torch.float16,
    use_async_offload=True,
)
use_async_offload=True is CUDA-only and transfers saved wavefields to pinned CPU memory. Lower-precision storage and temporal sampling trade gradient accuracy for memory savings; use interval 1 with float32 storage for strict gradient checks.
05 / Solver

Forward modelling

DeepGPR.compute advances the 2D or 3D Maxwell system with FDTD, applies CPML absorbing boundaries, records the requested electric-field component, and preserves the final solver state for continuation or differentiation.

Grid

Isotropic or anisotropic spacing

Pass one scalar dx or three values for independent x, y, and z grid spacing.

Stencil

Order 2, 4, or 8

Select the spatial finite-difference order with fdtd_order; the default is 2.

Boundary

Six-face CPML

pmlthick accepts one thickness or six boundary-specific values.

Polarization

Electric-field components

Source and receiver components use 0 = Ex, 1 = Ey, and 2 = Ez.

Gradient modes

mode=2 is the Ez-only material-gradient path for 2D Ez-TM modelling. mode=3 uses Ex, Ey, and Ez contributions and is required for 3D or other electric-field component model gradients.

07 / Return state

Outputs

  1. E_saved — saved electric-field history for model-gradient work and diagnostics.
  2. (Ex, Ey, Ez) — electric-field state at the final time step.
  3. (Hx, Hy, Hz) — magnetic-field state at the final time step.
  4. PML_Tuple — 24 CPML auxiliary state tensors.
  5. receiver_amplitudes — recorded data with shape (nstep, nt, nrx).
