Performance testing

Benchmark infrastructure, not unsupported claims.

The repository includes reproducible CPU and CUDA benchmark tools. Results depend on hardware, build, model, and solver configuration, so no universal speed figure is asserted.

Available tools

Two benchmark entry points.

CPU or CUDA

Deterministic runtime benchmark

benchmark_runtime.py measures median forward and backward times, process memory, CUDA memory where applicable, and can compare saved receivers and gradients against a reference run.

python tests/benchmark_runtime.py --device cpu --warmup 2 --repeats 7tests/benchmark_runtime.py ↗
CUDA

GPU timing and power sampling

benchmark_cuda.py reports separate median forward and backward times. Optional nvidia-smi sampling captures board power, utilization, memory use, temperature, and SM clock as diagnostic metadata.

python tests/benchmark_cuda.py --device cuda:0 --sample-powertests/benchmark_cuda.py ↗
Method

Compare like with like.

The test documentation requires matched arguments and environments for meaningful revision comparisons.

01 / CASE

Fixed workload

Use identical grid dimensions, time steps, shots, receivers, PML thickness, stencil order, storage dtype, sampling interval, and random seed.

02 / BUILD

Recorded software

Keep the PyTorch version, native backend build, Python environment, and source revision consistent.

03 / HW

Controlled hardware

For GPU comparisons, hold power limit and application clocks constant and report the specific device.

04 / WARMUP

Warmup and repeats

Run explicit warmup iterations, take multiple timed repeats, and compare medians rather than a single observation.

05 / CORRECT

Numerical comparison

Save a reference run and compare receiver data plus relative-permittivity and conductivity gradients.

06 / TRACE

Native profiling

The repository documents PyTorch profiling plus NVIDIA Nsight Systems and Compute for detailed CUDA investigation.

Results policy

Measured results will be published with context.

The repository currently provides benchmark programs and numerical verification reports, but not a stable cross-platform benchmark table intended for website publication. Performance results can be added when the hardware, software, configuration, commands, and revision are recorded together.
