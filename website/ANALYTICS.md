# Website statistics and optional visitor analytics

The website currently includes no visitor-tracking or advertising scripts. Download and repository statistics are generated by GitHub Actions and served from `data/stats.json`.

Recent PyPI download counts come from the PyPI Stats API. Cumulative downloads are rebuilt from a persistent, date-keyed daily history stored only on the repository's `stats-history` branch. Each refresh overwrites dates still visible to the API, retains older dates that have left the API window, and recalculates the total from the complete saved mapping. This makes reruns idempotent and preserves already tracked history without adding daily commits to `main`.

All PyPI counts exclude known mirrors. A download is a package-file download request, not a unique user or a verified installation. The public snapshot exposes `history_complete`; when it is false, the cumulative value is a verified lower bound from `first_tracked_date`, not an all-time count since the package's first release.

If the project later enables Cloudflare Web Analytics, obtain the official beacon token from the Cloudflare dashboard and add Cloudflare's current Web Analytics beacon immediately before `</body>` on each HTML page. Keep the token out of Python code and GitHub Actions logs, verify the script URL against Cloudflare's documentation, and document the change in the repository.

Do not add a placeholder token. The site is fully functional without visitor analytics.
